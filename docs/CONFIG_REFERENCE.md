# Configuration Reference

All configuration files and their key settings.

---

## `.env`

Top-level environment file.  Copy from `.env.example` and edit before running
`install.sh`.  **Never commit this file.**

| Variable | Required | Default in example | Description |
|---|---|---|---|
| `TZ` | ✅ | `Etc/UTC` | IANA timezone string for containers |
| `ZIGBEE_DEVICE` | ✅ | placeholder | Stable coordinator path (`/dev/serial/by-id/…`) |
| `MQTT_USER` | ✅ | `ha` | MQTT broker username |
| `MQTT_PASS` | ✅ | placeholder | MQTT broker password (use a strong value) |
| `MARIADB_ROOT_PASSWORD` | ✅ | placeholder | MariaDB root password |
| `MARIADB_DATABASE` | ✅ | `homeauto` | Shared application database name |
| `MARIADB_USER` | ✅ | `homeauto` | Application DB user |
| `MARIADB_PASSWORD` | ✅ | placeholder | Password for `MARIADB_USER` |
| `ANDROID_TV_IP` | ❌ | `192.168.1.60` | Default Android TV LAN IP for helper scripts |
| `BT_DEVICE_MAC` | ❌ | placeholder | Default Bluetooth device MAC |
| `BT_PAIR_PIN` | ❌ | _(empty)_ | Bluetooth pairing PIN (leave empty if not needed) |

## `ha/configuration.yaml`

Home Assistant configuration.  Copied from `ha/configuration.yaml.example` on
first install.  See the [HA Container docs](https://www.home-assistant.io/common-tasks/container/)
for full reference.

Key sections in this repo's example:

### `default_config`

Enables the standard HA integration bundle (logging, history, frontend, etc.).

### `mqtt`

```yaml
mqtt:
  broker: 127.0.0.1
  username: !secret mqtt_user
  password: !secret mqtt_password

recorder:
  db_url: !secret recorder_db_url
```

Credentials are read from `ha/secrets.yaml`.  With `network_mode: host`,
`127.0.0.1` resolves to the host's Mosquitto and MariaDB services.

### Helper action triggers

Helper scripts (ADB / Bluetooth) are NOT triggered via `shell_command`.
See [docs/ARCHITECTURE.md](ARCHITECTURE.md) for the MQTT action bridge pattern
and topic/payload schema.

## `ha/secrets.yaml`

HA secrets file.  Copy from `ha/secrets.yaml.example`.
**Never commit this file.**

```yaml
mqtt_user: ha
mqtt_password: <your MQTT_PASS value>
recorder_db_url: mysql://homeauto:<MARIADB_PASSWORD>@127.0.0.1:3306/homeauto?charset=utf8mb4
```

## `mosquitto/config/mosquitto.conf`

Mosquitto broker configuration.  Copied from `mosquitto.conf.example` on first
install.

| Directive | Value | Notes |
|---|---|---|
| `listener` | `1883` | Plain MQTT on all interfaces |
| `allow_anonymous` | `false` | Auth required |
| `password_file` | `/mosquitto/config/passwd` | Generated by `install.sh` |
| `persistence` | `true` | Retain sessions/messages across restarts |
| `persistence_location` | `/mosquitto/data/` | Bind-mounted from `./mosquitto/data/` |
| `log_dest` | `file /mosquitto/log/mosquitto.log` | Bind-mounted from `./mosquitto/log/` |

To add TLS or WebSocket listeners, see the
[Mosquitto conf reference](https://mosquitto.org/man/mosquitto-conf-5.html).

## `zigbee2mqtt/configuration.yaml`

Zigbee2MQTT configuration.  Copied from `configuration.yaml.example` on first
install.  Also writable by the Zigbee2MQTT frontend at runtime.

| Setting | Value | Notes |
|---|---|---|
| `homeassistant` | `true` | Publish HA MQTT discovery messages |
| `mqtt.server` | `mqtt://127.0.0.1` | Host-network Mosquitto |
| `mqtt.user` | _(set manually)_ | Must match `MQTT_USER` in `.env` |
| `mqtt.password` | _(set manually)_ | Must match `MQTT_PASS` in `.env` |
| `serial.port` | `/dev/zigbee` | Fixed in-container path |
| `frontend` | `true` | Enable web UI at `:8080` |
| `permit_join` | `false` | Enable temporarily when adding new devices |

Full reference: https://www.zigbee2mqtt.io/guide/configuration/

## `docker-compose.yml`

Controls the stack services.  Key settings:

| Setting | Value | Reason |
|---|---|---|
| `network_mode: host` | all services | Required for LAN multicast/mDNS discovery |
| `privileged: true` | `homeassistant` only | Required for some HA integrations (current phase) |
| `/run/dbus` volume | `homeassistant` | D-Bus access for Bluetooth integration |
| `/run/udev` volume | `zigbee2mqtt` | udev event access for adapter hot-plug |
| `devices` (`${ZIGBEE_DEVICE}:/dev/zigbee`) | `zigbee2mqtt` | Coordinator device mapping |
| `MQTT_USER` / `MQTT_PASS` env vars | `mosquitto` | Required for the Mosquitto healthcheck |
| `MYSQL_*` env vars | `mariadb` | Initializes DB/user and powers DB healthcheck |
| `depends_on: condition: service_healthy` | `homeassistant`, `zigbee2mqtt` | Wait for Mosquitto to be healthy before starting |
| `depends_on: mariadb service_healthy` | `homeassistant` | Wait for SQL backend before recorder startup |

### Image version policy

| Service | Tag | Notes |
|---|---|---|
| `homeassistant` | `:stable` | Tracks current HA stable release |
| `mosquitto` | `:2` | Tracks latest Mosquitto 2.x |
| `zigbee2mqtt` | `:2` | Tracks latest Z2M 2.x |
| `esphome` | `:stable` | Tracks current ESPHome stable release |
| `nodered` | `:4` | Tracks Node-RED major v4 line |
| `mariadb` | `:11` | Tracks MariaDB 11.x major line |

All images are re-pulled on `./update.sh --restart`.
See `docs/SUPPORT_BOUNDARIES.md` for the version pinning rationale.

## `/etc/ha-action-bridge.env`

Written by `install.sh` to pass MQTT credentials to the bridge service.
**Not part of the repo.**  Permissions: `0600` (root-only).

```bash
MQTT_HOST=127.0.0.1
MQTT_PORT=1883
MQTT_USER=<value from .env>
MQTT_PASS=<value from .env>
```

## Helper script environment variables

All ADB and Bluetooth scripts read environment variables.  The bridge sets
these automatically from the MQTT payload.  For direct invocation:

### ADB scripts (`scripts/adb/`)

| Variable | Required | Description |
|---|---|---|
| `ANDROID_TV_IP` | ✅ | LAN IP of Android TV (RFC1918 enforced) |

### Bluetooth scripts (`scripts/bt/`)

| Variable | Required | Description |
|---|---|---|
| `BT_DEVICE_MAC` | ✅ | Target device MAC address |
| `BT_PAIR_PIN` | ❌ | Pairing PIN (`bt_pair_trust.sh` only; empty = no PIN) |
